# Vector Thrust：Clarabel 凸优化火箭定点回收（SpaceX 式着陆）

二维火箭刚体仿真 + 凸优化动力下降制导。从任意空中状态开启自动模式后，火箭按 Falcon 9 的着陆方式回到发射台：**无动力下落 →（需要时）反推返航 → 在最优时刻点火、一次连续着陆燃烧 → 末端竖直下降 → 以 ~1.3 m/s 触地**。

## 为什么旧版本“不像 SpaceX”

| 问题 | 旧实现 | 现在 |
|---|---|---|
| 优化结果基本没被执行 | 只用了 MPC 的 `0.08·az`、`0.20·ax`，其余是手调反馈和分段下降速度表（25→18→5 m/s） | 规划的推力直接作为前馈，120 Hz 反馈只修正残差 |
| 时域不适合着陆 | 600 s / 5 s 一个节点，连点火时机都表示不了 | 自由终端时间，N = 40 个节点覆盖“从现在到触地”，节点间推力一阶保持（连续、无台阶） |
| 没有点火时机的概念 | 一直开着发动机慢慢往下“悬停式”降 | 燃料最优 ⇒ 先自由落体，在必须点火的那一刻点火（hover-slam） |
| 震荡 | 大幅摆动的 PD 姿态环，喷管 ±30° 来回打满（摆角速率只有 42°/s，一次反向就要 1.4 s） | 级联姿态环：角度→限幅角速度→角加速度→按推力换算摆角，限制 ±12° 摆角，带角速度前馈 |

同一套 120 Hz 非线性物理下的对比（旧版用同一求解器跑）：

| 场景 | 旧：用时 / 触地速度 | 新：用时 / 触地速度 / 落点误差 |
|---|---|---|
| 100 m 静止 | 13.4 s / 2.36 m/s | 7.8 s / 1.34 m/s / 0.00 m |
| 2000 m，+30 m/s | 110 s / 2.36 m/s | 38.8 s / 1.35 m/s / 0.00 m |
| 2000 m，−30 m/s | 91 s / 2.35 m/s | 32.8 s / 1.39 m/s / 0.00 m |
| 2000 m，x = +1000 m，vx = +100 m/s | 99 s | 约 44 s / ≤1.6 m/s / ≤0.1 m |
| 2000 m，x = −1000 m，vx = +100 m/s | 97 s | 约 42 s / ≤1.5 m/s / ≤0.1 m |

## 制导算法（`guidance.py`）

### 凸规划（`ConvexLandingPlanner`）

状态 `x = [水平位置, 高度, 水平速度, 垂直速度]`，控制是推力加速度 `u = [ux, uz]` 和无损凸化松弛变量 Γ。每次求解一个 SOCP（Açıkmeşe–Ploen 无损凸化，即 G-FOLD 的结构）：

- **动力学**：双积分器 + 重力 + **预测的气动阻力**（沿上一条规划轨迹、按规划姿态计算迎风面积，倾斜飞行时计入侧面阻力），推力一阶保持（精确离散化）；
- **推力锥**：`‖u‖ ≤ Γ`，`ρ_min ≤ Γ ≤ ρ_max`（无损凸化：最优解处 `‖u‖ = Γ`）；
- **倾角约束**：`uz ≥ cos θ(t_go) · Γ`，θ 随剩余时间收紧：远处允许大倾角机动，6 s 时 20°，最后 2 s 只允许 3°（竖直末段）；
- **滑翔锥**：以台面为顶点、半角 65° 的锥（软约束），防止贴地横飞；
- **执行机构速率**：油门变化率、侧向推力变化率（保证推力方向变化不超过 TVC 能转动箭体的速度），第 0 个节点钉在发动机当前推力上；
- **终端**：台面中心、水平速度 0、下沉 1 m/s，用精确 L1 罚函数实现，因此问题永远可行。

目标函数两种模式：点火前 `fuel`（最省燃料，给出“滑行 + 一次猛烧”的最优点火）；点火后 `smooth`（加速度能量 + 加加速度，推力平滑均匀）。

### 闭环（`AutonomousGuidance`）

1. **COAST / BOOSTBACK**：每 0.5 s 做一次黄金分割搜索最优飞行时间（点火临近时加密到 0.1 s）；发动机工作期间（反推返航）固定触地时间，保证相邻规划一致。发动机关闭时用冷气 RCS 把箭体对准即将到来的点火方向（发动机朝下迎风，SpaceX 式）。
2. **LANDING BURN**：规划显示“从现在到触地一次连续燃烧”即锁定触地时间，5 Hz 以平滑目标重规划；规划推力上限 85%，给反馈留 15% 余量。若因扰动无法按时到达，只把触地时间移到**最早可达**时刻（必要时依次放宽到 90%/97% 推力），绝不“多给时间”——那会导致贴地悬停。
3. **TERMINAL**：离地 12 m 且接近计划终点时，停止重规划，按匀减速下沉速率剖面竖直下降，同时以 ≤6° 倾角消除水平速度，~1.3 m/s 触地。
4. **内环**：规划推力前馈 + 位置/速度 PD 修正 → 推力向量 → 油门 + 期望推力方向 → 级联 TVC 姿态环（低推力时 RCS 协助）。

## 安装和运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

**启动后会直接播放一次演示着陆**（偏离 +1000 m、以 100 m/s 向外飞的返航场景），镜头自动把火箭和发射台一起框进画面并随接近拉近。按 `1`–`5` 随时重放五个测试场景；按 `R` 回到发射台（设置 `ROCKET_DEMO=0` 则启动时停在发射台）。也可以按 `T` 输入初始高度、水平位置和水平速度，再按 `M` 开启自动着陆。也可以：

```powershell
$env:ROCKET_AUTOPILOT = "1"
python main.py
```

绿色线是当前规划从“现在”到触地的完整轨迹（每 0.1 s 采样的精确轨迹，无需平滑），蓝色线是实际飞行轨迹。HUD 显示制导阶段（COAST / BOOSTBACK / LANDING BURN / TERMINAL）和剩余时间 T-GO。

### 画面与仪表（模拟舱风格）

- **火箭 / 尾焰 / 烟尘**（`visuals.py`）：Falcon 式一级箭体（圆柱明暗、黑色级间段、栅格舵、底部烧蚀渐变、随摆角偏转的喷管，150 m 以下展开着陆腿）；加色混合的分层尾焰（黄色核心、马赫菱形、橙色外焰、喷口辉光），近地时被地面截断并横向铺开；尾迹烟、地面扬尘、RCS 喷气；带边灯的着陆台。
- **仪表**（`cockpit.py`）：顶栏（任务时钟、AUTOLAND/MANUAL、求解器状态）；左上 NAV 轨迹图；左下飞机式 **PFD**（姿态球 + 倾角刻度、速度带、高度带、升降速度、速度矢量符号、洋红色指令倾角标记）；右上 **自动驾驶面板**（接通状态、COAST→BOOSTBACK→LANDING BURN→TERMINAL→LANDED 阶段灯、T-GO、求解状态、推力余量、告警灯）；右下 **发动机面板**（带握把的油门滑杆 + 洋红色指令值、摆角半圆表、推力与推重比、RCS 指示）；**最后 50 m 屏幕下方淡入着陆区精度监视器**：台面示意、±10 m 标尺与 1 m/3 m 容差带、火箭相对台面的实时位置、预测触地点、侧向速度箭头、POS/VEL/ATT 三个判定灯，触地后显示最终误差。
- 颜色遵循航电惯例：绿 = 正常/激活，青 = 数据，洋红 = 自动驾驶目标，琥珀 = 注意，红 = 警告。F1 打开按键帮助。

主要按键：`1`–`5` 演示着陆；`M` 自动着陆开关；`T` 设置初始状态；`W/S` 油门；`A/D` 喷管；`Space` 关机；`P` 暂停；`R` 重置；`Tab` 力和速度矢量；`F1` 帮助。

**3D 气流**（`web3d/fluid.js`，WebGL2 GPU）：不可压“稳定流体”三维网格，默认 64×64×96、1.0 m（64 m × 64 m × 96 m）。**网格坐标轴固定为世界坐标（东、北、天），只随箭体平移、不随相对风转动**；来流（风速减去网格速度）从上游一侧的边界进入，网格速度变化作为运动坐标系的惯性加速度整体施加到流场上，因此相对风方向变化时流场连续、不重置。箭体位于网格上游约 30% 处（随来流方向平滑移动）。速度：RK2 回溯半拉格朗日平流 + 涡量约束 + 24 次 Jacobi 压力投影（热启动）；箭体（箭身、发动机段、栅格舵、着陆腿）和地面为固体，发动机尾流是动量与燃气密度源。表面压力在箭体上积分得到力系数与压心。
**无论主视图是否显示气流，流场都在持续计算**：风洞截面窗口始终实时显示，CFD 力系数也始终发往服务器；按 `C` 时由它驱动作用在箭体上的气动力（限制在工程模型 0.5–2 倍内）。网格可调：`?cfd=low`（40×40×60、1.6 m，弱显卡 / 软件渲染）、`?cfd=high`（96×96×128、0.72 m），或 `?grid=48x48x72&cell=1.3` 自定义。

气流显示参考相邻 `fluid/` 项目（`scenes.c` 风洞场景的彩色条带染料、`fluid.c` 的 MacCormack 平流与色标自动缩放、`render.c` 的曝光映射与 inferno / icefire 色图）：

- **示踪流管**：箭体上游横跨来流放置一排“烟耙”，按位置注入不同色相的示踪染料，三排流管，中间一排正好落在风洞截面内；染料用 MacCormack 平流（带极值限制），边缘清晰。注入每隔一段时间短暂中断，形成随气流运动的“时间线”，可以直接看出流速快慢。发动机燃气单独存储，显示为灰白色。
- **风洞截面窗口**（右侧，可拖动、拖右下角调整大小、滚轮缩放、双击复位）：竖直截面过箭体中点，取**世界坐标系东—天或北—天平面，画面上方始终为天向**，箭体按真实姿态绘制（竖直下落时就是竖直的）。显示量：染料 / 速度大小（inferno，m/s）/ 截面法向涡量（icefire，1/s，蓝为顺时针、橙为逆时针）/ 压力系数 Cp（icefire）/ 纹影（示踪剂浓度梯度）；色标按统计量平滑自动缩放并标出数值。可选示踪粒子（随截面内速度场运动）；受力层显示作用在箭体上的气动合力（琥珀色，作用在压心）、实时 CFD 表面压力合力（青色虚线）、质心与压心符号；左上角为来流方向、速度、马赫数和攻角，左下角为比例尺和坐标轴。
- 主视图 `F` 开关三维气流体积（只影响显示，不影响计算）；`B` 在染料 / 涡量 / 速度间切换，主视图与风洞截面同步。气流显示开启时主画面的规划与历史轨迹隐藏，轨迹仍可在导航显示器查看。

**姿态仪表（阿波罗 FDAI 式，`web3d/instruments.js`）**：金属面板、螺钉、玻璃反光；球面按经纬贴图逐像素绘制并带光照（上白下黑，俯仰线每 10°，03/06 等数字随球面弯曲，航向子午线 N/03/06/E…）；固定的橙色基准符号；三根带阴影的黄色误差针（上 = 滚转、右 = 俯仰、下 = 偏航）；外圈滚转刻度 + 固定滚转指标 + 活动天空指针；ROLL/PITCH/YAW RATE 三个速率窗；GUID/OFF 状态旗；航向与俯仰数字窗。球上仍标出速度/逆速度方向和着陆台方向。

**着陆区显示器（多功能显示器式 ND）**：带 8 个可点击软键的 MFD 边框（RNG ▲/▼、AUTO 自动量程、N-UP/TRK-UP、PLAN 规划轨迹、HIST 历史航迹、WIND 风、PRED 10 s 趋势矢量）；罗盘刻度环、距离环；着陆台按真实标记（黄色双环、X、混凝土台面）绘制；最后 50 m 自动切到 12 m 量程并显示 1 m / 3 m 容差圈、四条着陆腿的实际落点、ΔE/ΔN；品红色规划轨迹和预测触地点 TD；角落数据块 GS/TRK/DIST/BRG/ALT/V/S/TGO。着陆成功后不再弹出大号 LANDED 横幅，只在显示器上显示 ON PAD · ENGINE SAFE。

所有场景着陆燃烧中都没有悬停或上升（离地 1.5 m 以上时下沉速度始终 > 0.8 m/s），接地前也没有来回摇摆（最后 8 m 内箭体最多做一次平缓的姿态回正）。防摇摆措施：姿态环按执行机构实际能提供的角加速度限制角速度指令（不会冲过头），推力方向指令有转动速率上限（近地更慢），规划器对横向推力的变化（jerk）加重惩罚，低空短燃烧的倾角预算按高度收紧（有真实横向速度时放开），末段横向指令一阶滤波、触地前箭体回正到 ≤ 0.6°。
通过条件：LANDED、落点 ≤ 3.5 m、下沉 ≤ 2.5 m/s、水平速度 ≤ 1.5 m/s、姿态 ≤ 5°。3D 比 2D 难（侧风、箭体升力在高动压下与推力方向相反、姿态滞后），所以目前精度是米级；台面标记半径 13 m。
